# alex-wilkinson.ca

My personal site: one long page covering Houski, Simple Universal Language,
Nail, and two books in progress. Written in [Nail](https://github.com/AlexTDWilkinson/Nail)
and served as a single static-rendered page from the same DigitalOcean droplet
as `sul.alex-wilkinson.ca` and `nail.alex-wilkinson.ca`.

## Layout

| path | what it is |
|---|---|
| `site.nail` | entry point: routing, static mounts, `http_server` |
| `nail/ui.nail` | colour vocabulary, buttons, icons, section headings |
| `nail/layout.nail` | document shell, sticky header, footer |
| `nail/pages/home.nail` | the page itself, and the 404 |
| `static/js/site.js` | theme toggle and the hold-to-reveal email |
| `styles/tailwind.css` | the handful of rules Tailwind cannot express |
| `scripts/` | build and deploy |
| `deploy/` | droplet provisioning, copied verbatim from the SUL repo |

`server/src/main.rs` and `server/Cargo.toml` are both generated by `nailc` on
every build. Never edit them; `main.rs` is gitignored.

## Local

```bash
./scripts/nail-build.sh --run    # http://127.0.0.1:3002
```

The build regenerates `static/styles/app.css` with the pinned standalone
Tailwind CLI (downloaded and cached under `target/`, no npm), transpiles
`site.nail` to Rust, and builds it. `PORT` overrides the port.

## Deploy

```bash
./scripts/deploy.sh              # host comes from DEPLOY_HOST in .env
```

Builds locally and ships a finished binary plus `static/` to the droplet, then
restarts the service and health-checks it. Nothing is ever compiled on the box.

The app is registered as `portfolio` on port 3002, binary `alex-portfolio`,
serving `alex-wilkinson.ca` and `www.alex-wilkinson.ca`. If the box is ever
rebuilt:

```bash
scp -r deploy root@<ip>:/tmp/deploy
ssh root@<ip> 'bash /tmp/deploy/provision-base.sh'   # no-op on a live box
ssh root@<ip> 'bash /tmp/deploy/add-app.sh --name portfolio --port 3002 \
    --bin alex-portfolio --host "alex-wilkinson.ca, www.alex-wilkinson.ca"'
```

See `deploy/README.md` for the full runbook.

## The email address

It is not in the HTML, and it is not a readable string in the JavaScript
either: `static/js/site.js` assembles it from character codes, and only after a
deliberate two-second press of the button. To change it, edit `LOCAL_CODES` and
`DOMAIN_CODES` in that file.
